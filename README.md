# Data Redundancy Removal System

## Project Description

A Flask-based cloud computing project that detects duplicate user data before storing it in the database.

## Features

- User data registration
- Duplicate email detection
- SQLite database storage
- Prevention of duplicate records
- Simple web interface
- User records display

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite

## How to Run

1. Install Flask:
   pip install flask

2. Run the application:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000
